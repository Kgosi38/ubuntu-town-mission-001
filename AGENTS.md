# Repository Operating Rules

- Read before changing.
- Work only on the current feature branch.
- Never push directly to main.
- Never expose, print, commit or request secret credentials.
- Do not modify Cloudflare or Supabase production resources.
- Preserve the existing site purpose and visual identity.
- Keep changes minimal and explain every changed file.
- Run available checks before declaring success.
- Produce reports/HH-001-REPORT.md.
- Stop for human review before merge or production release.
